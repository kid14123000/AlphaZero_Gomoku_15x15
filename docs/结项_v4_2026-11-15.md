# v4 结项 —— 15×15 五连 AlphaZero（2026-11-15 截止）

> 本文只写**实测到的东西**。推断处标注「推断」。判据自 2026-11-14 起写死不改：
> **白胜率 ≥20% / 均手 ≥24 / 速杀(≤11手) <15%**。

---

## 1. 这一版是干什么的

v4 = 15×15 自由规则五连，V24Net（128ch × 8 残差 + BN，2,501,226 参数），
4-plane 输入（ch0 我 / ch1 对手 / ch2 恒 1 / ch3 上一手），value 头带隐藏层 + tanh。

主线目标只有一个：**解决白崩**（白棋胜率长期卡在 13~19%，棋局退化成"先手即胜"）。

## 4. 试过什么、结论是什么

| 方向 | 做法 | 结论 |
|---|---|---|
| 分层采样（4 类 B_win/B_lose/W_win/W_lose） | `curriculum_ctl.py` 60s 轮询写 `sync/class_weight.json`，三档 collapse/mid/healthy | 有效但**有软天花板**：mid 档把 W_win 供给砍 27%，白胜率一到 20~27% 控制器就切 mid，然后掉回 14~19%（实测反复 4 次） |
| 白赢储库 `ww_reservoir`（deque maxlen=24000） | 白赢局无限重放 | batch 15234 触顶，FIFO 开始驱逐老白赢局；无法与"题目变难"分离 |
| value 目标 z → q（MCTS 根 Q 软标签） | `--value_target q` | **失败**。实测 `|Q|` 均值 0.83~0.98（z 恒 1.0），只软了 11%；更糟的是**白赢的局里 50~62% 的 Q 判定"黑棋赢"**（黑赢的局 99% 正确）。原因是 q 记录"当时搜索怎么想"，而白赢多是黑方中途失误，出事前搜索必然认为黑赢。→ 回退到 z |
| 冻结 / λ 降权 / 加噪 / 砍算力 | 多处 | 已证伪 ≥3 次：都是"减信息"，结果只降低拟合不改善判断。筛选准则定为 **加约束、不减信息** |
| 均衡首手（借鉴 AlphaGomoku value filter） | 见 v24b 仓库 | 尚未在 v4 上实证 |

## 5. 没解决的（老实说）

1. **白崩没有根治**。速杀 19.5% 说明白方经常连防守机会都没有。而 Allis 已证明：自由规则 15×15 黑方必胜 ⇒ 若不动规则，"白棋不崩"在数学上不可能，只能压缩差距。
2. **控制器是软天花板**：只要白胜率接近 20%，供给就被砍，形成振荡而非持续爬升。想破这层，得改"加约束"的方式（不是砍 W_win，而是提高白赢局的质量），没来得及做。
3. **内部只有自对弈指标，缺代际 PK**。除了 vs Rapfi 那 18 局，没有做过"this gen vs that gen"的定量互比 ⇒ "哪一代最强"缺证据链。
4. **value 头有稳定的盲区**：单次前向看不出"对手已成五/活四"。实测 263 个必败局面，自估值均值 28.2%，19.8% 仍给 >50%；MCTS 100 sims → 6.6%，400 sims → 4.1%（靠搜索救回来）。这是结构性缺陷，不是参数问题。

## 8. 留给下一版（v44）的建议

- 白方短板在 **policy 的攻击链**，不在 value：VCF/VCT 扫描（30 局）黑方 100% 的局有 ≥2 手连续攻击链、均长 4.07；白方只有 33%、均长 1.23。
- 破局点更可能在 **开局多样性**（v36 的"随机开局"曾用 20:0 完封旧王座），而不是继续调采样权重。
- 若继续 q 系思路：q 只能进 value 的辅助项（比如 z 为主、q 做一致性正则），**不能当主目标** —— 理由见 §4。
