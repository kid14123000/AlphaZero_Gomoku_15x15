只放两份：**终版最优** 与 **对外锚点基线**。两者都是 126 tensor / 2,501,226 参数（V24Net 128ch×8 残差 + BN），可直接 `torch.load(map_location='cpu')`。

| 文件 | 代次 | 大小 | 为什么带它 |
|---|---|---|---|
| `ckpt_it16946.model` | it16946 | 9.6 MB | **终版最优**：最后一次训练 run 的末代，落在全 run 行为指标最好的 145 局窗口内 |
| `ckpt_it15853.model` | it15853 | 9.6 MB | **对外锚点基线**：`docs/外部锚点_15x15_基线.md` 里 vs Rapfi depth5 的 27.8% 就是这副打出来的，不带它该文档无法复现 |

最后一段白胜率 22.8% 是全 run 最高，且不是靠"局变短"换来的（均手 25.5 同时是全 run 第二高、速杀 19.3% 处于低位）。
尾部窗口：近 200 局 22.5% / 均手 25.1；近 100 局 18.0%。

**这不是 PK 结论**：v4 只做过 vs Rapfi 的外部锚点，没有做过代际间互比 PK。按项目既定规矩（代表权重取窗口不取最新代），这里取的是"行为指标最好那段窗口的末代"——它恰好是全线末代，是巧合不是择优理由。

## 什么时候该换掉 it16946

- 做了代际 PK 且发现别的代更强；
- 或者重开训练线（v44 及以后），那就不该再用 v4 的权重。
